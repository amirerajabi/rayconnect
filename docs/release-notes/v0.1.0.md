The first release of Raylit: a simple V2Ray / Xray client for the desktop. Paste a share link or a subscription, press
the big button, and you are connected.

From now on Raylit updates itself: on Windows and Linux, wait for **Restart to update** in the status bar (or choose
**Check for updates** in Settings → Updates).

### Downloads

- **Windows:** `Raylit-Setup-0.1.0.exe`
- **macOS (Apple silicon):** `Raylit-0.1.0-mac-arm64.dmg`
- **Linux:** `Raylit-0.1.0-x86_64.AppImage`

Each download includes [Xray-core](https://github.com/XTLS/Xray-core) (MPL-2.0, unmodified), so you can connect right
away. Settings → Xray core can download a newer Xray or use one you already have.

### What it does

- **Servers:** VMess, VLESS (REALITY, XTLS Vision), Trojan and Shadowsocks, from `vmess://`, `vless://`, `trojan://`
  and `ss://` links. Copy one and press **Ctrl+V** in the window.
- **Subscriptions:** add the link from your provider. It updates on its own and shows data used and days left.
- **One button to connect**, from the window or the tray icon, which turns green while connected.
- **System proxy or Proxy only:** System proxy sets your computer's proxy while connected and puts your own setting
  back afterwards, even after a crash. Proxy only opens HTTP `127.0.0.1:10819` and SOCKS `127.0.0.1:10818`; these
  ports do not clash with v2rayN's.
- **Real delay tests:** **Test** checks every server with a real request, **Fastest** sorts by delay.
- **Routing:** everything through the server, or Iranian, Chinese or Russian sites direct. Optional ad blocking.
- Live speed graph, the core's log, light and dark themes, and a command palette (**Ctrl+K**).

The builds are not code-signed yet. On Windows, SmartScreen may warn on first run: choose **More info → Run anyway**. On
macOS, right-click the app and choose **Open** the first time.
