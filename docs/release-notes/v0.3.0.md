Raylit is now **RayConnect**. Same app, new name.

If you have Raylit 0.1.0 or 0.2.0, it updates itself and becomes RayConnect: on Windows and Linux, wait for **Restart
to update** at the top of the window (or choose **Check for updates** in Settings → Updates). Your servers,
subscriptions and settings come along.

### Downloads

- **Windows:** `RayConnect-Setup-0.3.0.exe`
- **macOS (Apple silicon):** `RayConnect-0.3.0-mac-arm64.dmg`
- **Linux:** `RayConnect-0.3.0-x86_64.AppImage`

Each download includes [Xray-core](https://github.com/XTLS/Xray-core) (MPL-2.0, unmodified).

### What changes

- The name: RayConnect, in the window, the tray, the Start menu and the installer.
- The project moved to https://github.com/amirerajabi/rayconnect. Old links to `raylit` still lead there.
- Your data moves from the `Raylit` folder to `RayConnect` the first time the new version starts, so nothing is lost.
- If Raylit started when you signed in to Windows, RayConnect does too.

The builds are not code-signed yet. On Windows, SmartScreen may warn on first run: choose **More info → Run anyway**. On
macOS, right-click the app and choose **Open** the first time. On macOS the renamed app is a new `RayConnect.app`; you
can delete the old `Raylit.app`.
