Your own routing rules, like v2rayN's: decide which sites go through the server, which go direct, and which are blocked.

If you have RayConnect (or Raylit) installed, it updates itself: on Windows and Linux, wait for **Restart to update** at
the top of the window (or choose **Check for updates** in Settings → Updates).

### Downloads

- **Windows:** `RayConnect-Setup-0.4.0.exe`
- **macOS (Apple silicon):** `RayConnect-0.4.0-mac-arm64.dmg`
- **Linux:** `RayConnect-0.4.0-x86_64.AppImage`

Each download includes [Xray-core](https://github.com/XTLS/Xray-core) (MPL-2.0, unmodified).

### New: routing rules

Settings → **Routing rules** (or **Edit rules** under the power button):

- **Whitelist or blacklist.** Choose what happens to sites none of your rules mention: they use the server (whitelist)
  or go direct (blacklist, so only the sites you list use the server).
- **Your own rules.** Give a rule a name, choose **Through the server**, **Direct** or **Block**, and list its sites and
  addresses, one per line: a site (`example.com` covers its subdomains), a word (`google`), an IP or range
  (`91.108.0.0/16`), a pasted web address, or Xray's lists such as `geosite:category-ir` and `geoip:ir`. The editor
  shows what it understood as you type.
- **Order matters.** Rules are checked from the top and the first match decides; move them up or down, or switch one
  off without deleting it.
- **Templates:** Iranian sites direct, Telegram through the server, YouTube and Google through the server, block ads.
- Changes apply at once, also while connected. Everything is in Persian too.

### Fixes

- A connection that was cut off right after a request (for example by a block rule) could stop the RayConnect engine.
  It now carries on, so your system proxy is never left pointing at nothing.

The builds are not code-signed yet. On Windows, SmartScreen may warn on first run: choose **More info → Run anyway**. On
macOS, right-click the app and choose **Open** the first time.
